# Data files, every record

## What it is

This note quotes every record of the repository's JSON Lines data files. A **JSON Lines** file holds one JSON object per line. Together these files are the inputs the program reads (prompts, emails, questions, tasks), the correct answers it is graded against, and the answers it recorded from real models so that tests can replay them.

## Why this repository uses it

The numbers in the README are computed from exactly these records. Reading them tells you what the program is asked to do and what a correct answer looks like. Nothing is hidden in a binary file.

## Where it appears

| File | What it does with this technology |
| --- | --- |
| `data/questions/dev.jsonl` | 30 records |
| `data/questions/test.jsonl` | 120 records |
| `evals/hand_grades.jsonl` | 30 records |
| `tests/fixtures/recordings/qwen2.5-1.5b.jsonl` | 302 records |

## How it works underneath

Each line is parsed on its own with `json.loads`. The files are read once at start-up (or, for recordings, kept in a dictionary keyed by the request's fingerprint). Long text inside a record is a normal JSON string with `\n` for line breaks, which is why a record that looks like several lines of text is still one line of the file.

Embedding vectors, where present, are stored as base64 text of 32-bit floating-point numbers (see `jsonl.md`).

## Mistakes people make

- **Editing a record by hand.** Many records are generated by a script or recorded from a model; change the source and regenerate.
- **Reordering lines.** Some files are read in order (tasks, questions); a recording is looked up by key and does not care.
- **A trailing comma or an extra bracket.** Each line must be a complete JSON object on its own.

## Check yourself

1. How many records does the first file hold?

   *Answer:* 30.

2. What separates records?

   *Answer:* A newline; there are no commas between records.

3. Why are recorded model answers committed?

   *Answer:* So tests and demos replay the same answers offline.

4. What does a record's `id` do?

   *Answer:* It names the item so results can refer to it.

5. How is a long text kept on one line?

   *Answer:* JSON escapes each line break inside text as `\n`.
